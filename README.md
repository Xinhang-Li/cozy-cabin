# 温馨小屋 🏡

一个星露谷风格的治愈系 2D 小屋生活模拟游戏：四个房间、四位由 AI 驱动的 NPC、三只宠物，纯陪伴，不打工。

## 玩法

- **移动**：WASD / 方向键　**互动**：E / 空格　**关闭**：Esc
- 走到床边睡觉进入新的一天
- 靠近 NPC 按 E：聊天（AI 实时生成对话，NPC 有独立记忆和好感度）或玩专属小游戏（烘焙 / 五子棋 / 修 Bug / 哲学问答）
- 三只宠物：橘猫橘子、高冷肥猫煤球、跟屁虫小狗豆豆，按 E 摸摸
- 电视会播 AI 生成热点新闻；所有家具可互动
- 右上角：存档/读档（含文件备份）、背包（好感礼物）、角色卡（自定义 NPC 人设）、AI 设置

## 配置 AI（每位玩家各自设置）

游戏本身不含任何 API Key。首次游玩请点右上角「⚙️ AI 设置」，填入你自己的 OpenAI 兼容接口信息：

- Base URL（如 `https://api.openai.com/v1`、`https://api.moonshot.cn/v1`）
- API Key
- 模型名

配置只保存在你自己浏览器的 localStorage 中，不会上传。不配置也能玩：小游戏、宠物、家具、看电视（内置兜底新闻）都正常，NPC 聊天会使用内置台词。

## 本地运行

```bash
npm install
npm run dev
```

## 技术栈

React + TypeScript + Vite + Tailwind，Canvas 像素渲染，无后端。
